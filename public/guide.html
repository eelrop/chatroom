Tribe Chatroom User Guide

Regular User Guide

Logging In / Registering

  • Click "Log In" to enter credentials or "Register" if you are new.
  • You must agree to the "User Policy" during registration.
  • Once logged in, your chat will be active and messages will appear instantly.

Sending Messages

  • Type into the input box and press Enter or click "Send".
  • Your message appears in the chat for everyone.

Using Emojis

  • Click the "Emoji" button to open the emoji popup.
  • Click an emoji to insert it into your message.

Sending GIFs

  • Type a keyword in the "GIF Search" box.
  • Click "Search" and choose a GIF to send.

Replying to Messages

  • Click the "Reply" button beside any message.
  • A preview appears above your input.
  • Send your reply and it will show as a quote.

Deleting Your Messages

  • You can delete your own messages by clicking the "Trash" button beside them.

Viewing Active Users

  • Click the "Users" button to view all online users.
  • Admins and Moderators will be tagged accordingly.

Account Settings

  • Click "Account" to change your email, password, or username.
  • Updating Username: Changes will be reflected in new messages; past messages will display your new name except where required for moderation logs.
  • Updating Email Address: Your registered email can be updated at any time. This is required for password recovery.
  • Password Recovery: Use the "Forgot Password" option. Enter your registered email address. If the request is made from your usual IP address, a token will be generated by the server. Requests from unknown IP addresses will not work and you may need to contact Admin.

Reporting Abuse

  • If you see a message that violates the rules (harassment, hate speech, spam, etc.), you can report it.
  • Click the "Report" button next to the message you want to report.
  • Provide a short reason for the report (e.g., spam, abuse).
  • Admins will review your report and take action if necessary.
  • All reports are reviewed confidentially.

Tips

  • Messages remain visible even if you log out.
  • If login issues occur, refresh the page.
  • Usernames are color-coded:
    • You - light blue
    • Other users - green
    • Admins - gold
    • Moderators - red

Moderator Guide

Moderators have all the functionality of regular users, plus:

Clear Chat

  • Click "Clear Chat" to erase all messages (use responsibly).

Delete Any Message

  • Moderators can delete any user's message that violates the rules.

Admin Guide

Admins have all Moderator abilities plus full system control:

Accessing Admin Panel

  • Click the "Moderate" button (Admins only).
  • Enter the admin password to log in.

Managing Users

  • Promote to Admin - grants full admin powers.
  • Promote to Moderator - grants moderator powers.
  • Demote to User - removes admin/moderator status.
  • Delete User - removes the account entirely.
  • Block IP - blocks the user's IP from accessing chat.

Managing Blocked IPs

  • View all blocked addresses.
  • Unblock IPs if necessary.

Handling Abuse Reports

  • View submitted reports.
  • Click "Clear Reports" to delete all reports.

Profanity Filter

  • Edit the "Bad Words" and "Safe Words" lists.
  • Save changes to update the filter live.
